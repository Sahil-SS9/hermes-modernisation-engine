Status: ACTIVE isolated direct BUILD under the owner's 20 October instruction. Point 4 remains HOLD. This plan decomposes, and does not replace or shrink, the preserved original design in `../PLAN.md`.

Goal: turn the existing reported-test preview into an independently checking, bounded, resumable upgrade workflow with honest native interfaces. No live install, paid/model egress, arbitrary real-project execution or public publication.

Architecture: preserve the imported evidence lane as reported-only. Add a strict protected behavioural contract and a separately stored, engine-collected observation lane. Run signed exact operations through the existing rootless executor, send inputs only over bounded stdin and compare actual responses against expectations retained outside the app's mount. Persist lifecycle claims, engine-owned candidate identities, authority correlation and fenced outcomes before accepting proof. All intended frontends use the same service; owner keys are enrolled only through trusted operator configuration, never tool arguments. No consumer signing endpoint.

Implementation: Python standard library + existing optional cryptography dependency, SQLite, already pinned offline rootless images. Initial independently exercised adapter is an explicit JSON request/response process contract; other languages/effect adapters are unsupported until separately exercised. This does not relabel self-reported JUnit as independently captured behaviour. No mandatory daemon.
